# TL Scholarship Management Dashboard

ระบบสารสนเทศเพื่อการบริหารจัดการและสรุปผลทุนการศึกษา — วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์

🌐 https://thaluangcementhaianusorn.github.io/scholarship-system/

## ฟังก์ชันของระบบ
- แดชบอร์ดสรุปสถิติและงบประมาณทุนการศึกษา (ซิงก์ข้อมูลอัตโนมัติทุก 30 วินาที)
- จัดอันดับผู้รับทุน แผนกวิชา และหน่วยงานผู้ให้ทุน
- สรุปยอดเงินและจำนวนทุนจากหน่วยงานภายนอก
- ฐานข้อมูลแหล่งทุนและหน่วยงานผู้สนับสนุน
- ค้นหา/กรองตามแผนกวิชา ระดับชั้น ประเภททุน ปีการศึกษา
- ประกาศประชาสัมพันธ์ทุนการศึกษา
- ยื่นสมัครทุนออนไลน์พร้อมแนบเอกสาร + ตรวจคุณสมบัติอัตโนมัติ + ติดตามสถานะ
- Admin: จัดการทุน (จำนวน/โควตา/คุณสมบัติ), สถานะใบสมัคร, ผู้รับทุน, แหล่งทุน, ประกาศ, แผนกวิชา
- ส่งออกใบสมัครและรายงาน PDF ขนาด A4, CSV และสำรองข้อมูล JSON

## สถาปัตยกรรม: ใช้ GitHub เป็นฐานข้อมูล
| ส่วน | ที่เก็บ | การเข้าถึง |
|---|---|---|
| เว็บไซต์ + `data/public.json` (ข้อมูลสาธารณะ ปิดชื่อแบบย่อ ไม่มีข้อมูลส่วนบุคคล) | repo นี้ (Public) | ทุกคนอ่านได้ |
| `db.json` ฐานข้อมูลเต็ม + `uploads/` ไฟล์แนบ | repo `scholarship-db` (**Private**) | เฉพาะผู้ดูแล |

- **ผู้ดูแล** เข้าสู่ระบบด้วย GitHub Fine-grained token (Contents: Read and write บน `scholarship-db` และ `scholarship-system`) ทุกการแก้ไขเป็น commit จึงมีประวัติย้อนหลังและกู้คืนได้
- **นักศึกษา** ยื่นใบสมัครผ่าน Relay (Google Apps Script ใน `relay/Code.gs`) ที่ถือ token ไว้ฝั่งเซิร์ฟเวอร์ — ไม่มี token อยู่ในหน้าเว็บ

## ติดตั้ง Relay รับใบสมัคร (ครั้งเดียว)
ดูขั้นตอนที่หัวไฟล์ `relay/Code.gs` แล้วนำ Web app URL ไปใส่ที่ ผู้ดูแล → ตั้งค่า → Relay URL

## โครงสร้างไฟล์
```
index.html            หน้าเว็บหลัก (SPA)
assets/css/app.css    ธีม/ดีไซน์ (รองรับโหมดมืด, มือถือ, พิมพ์ A4)
assets/js/            app (router) · pages (หน้าสาธารณะ) · admin · store (GitHub DB) · model · print · charts
data/public.json      ข้อมูลสาธารณะ (สร้างอัตโนมัติเมื่อผู้ดูแลบันทึกข้อมูล)
relay/Code.gs         Google Apps Script สำหรับรับใบสมัคร
legacy/               ระบบเวอร์ชันเดิม (เก็บไว้อ้างอิง)
```
